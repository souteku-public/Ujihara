## 1. アプリケーション概要

### 何をするツールか

SRT (Secure Reliable Transport) プロトコルで配信されているライブストリームに接続し、映像・音声のエンコード情報をリアルタイムで取得・表示します。

```
配信機器・エンコーダー          このアプリを実行する PC              ブラウザ
 [SRT Listener]   ←── 接続 ──  [srt_analyzer_web.exe]  ←──  [Chrome / Edge]
   (待ち受け側)       (Caller モード)   ffprobe で解析        結果を表示
```

### 主な用途

- 配信機器やエンコーダーの出力コーデック設定の確認
- 映像フォーマット（解像度・フレームレート・ビットレート等）の検証
- 音声フォーマット（サンプルレート・チャンネル数等）の確認
- 複数の Latency 値での接続テスト

### バックエンド

| 役割 | 使用ソフトウェア |
|---|---|
| SRT 接続・ストリーム解析 | **ffprobe** (ffmpeg 同梱) |
| Web サーバー | **Flask** (Python) |
| フロントエンド | HTML / CSS / JavaScript (外部ライブラリなし) |

## 2. 検出できる SRT ストリームの条件

### 接続モード

本ツールは **Caller（発信）モード** で動作します。  
接続先の機器は **Listener（待ち受け）モード** である必要があります。

| 接続先モード | 対応 |
|---|---|
| Listener モード | ✅ 対応 |
| Caller モード | ❌ 非対応 |
| Rendezvous モード | ❌ 非対応 |

### パスフレーズ（暗号化）

| 暗号化設定 | 対応 |
|---|---|
| 暗号化なし | ✅ 対応 |
| AES-128 / AES-256 (パスフレーズあり) | ✅ 対応（パスフレーズの入力が必要） |

> パスフレーズは 10〜79 文字の文字列です。設定が間違っている場合、接続はタイムアウトになります。

### 映像・音声コーデック

ffprobe が対応しているコーデックであれば解析可能です。代表的な例を示します。

**映像**

| コーデック | 例 |
|---|---|
| H.264 (AVC) | ✅ |
| H.265 (HEVC) | ✅ |
| H.266 (VVC) | ✅ |
| MPEG-2 Video | ✅ |
| その他 ffprobe 対応コーデック | ✅ |

**音声**

| コーデック | 例 |
|---|---|
| AAC | ✅ |
| MP3 | ✅ |
| PCM | ✅ |
| AC-3 / E-AC-3 | ✅ |
| その他 ffprobe 対応コーデック | ✅ |

### コンテナフォーマット

SRT でよく使われる以下のコンテナに対応しています。

| コンテナ | 備考 |
|---|---|
| MPEG-TS (Transport Stream) | 放送・ライブ配信で最も一般的 |
| MPEG-4 / fMP4 | 一部エンコーダーで使用 |

| Frame Rate | フレームレート（fps） | ✅ | − |
| Pixel Format | ピクセルフォーマット（例: yuv420p） | ✅ | − |
| Color Space | 色空間（例: bt709） | ✅ | − |
| Color Transfer | 伝達特性（例: bt709, smpte2084） | ✅ | − |
| Color Primaries | 色域（例: bt709, bt2020） | ✅ | − |
| Sample Rate | サンプリング周波数（例: 48,000 Hz） | − | ✅ |
| Channels | チャンネル数（例: 2） | − | ✅ |

### フォーマット情報（コンテナ全体）

| 項目 | 内容 |
|---|---|

### その他

- **接続成功時の SRT URL** をブラウザ上でコピーできます
- **解析結果を JSON ファイル**でダウンロードできます

## 4. 動作に必要なネットワーク環境

### 通信の方向

本ツールは **外向き（アウトバウンド）** の通信のみ行います。PC 側のポートを開放する必要はありません。

```
このアプリの PC  ──→（アウトバウンド UDP）──→  SRT Listener
```

### 必要な通信許可

| 通信 | 方向 | プロトコル | 条件 |
|---|---|---|---|
| SRT 接続 | アウトバウンド | **UDP** | 接続先 IP・ポートへの UDP 送信が許可されていること |
| Web UI | ローカルループバック | TCP | 127.0.0.1:8765 のみ（外部からアクセス不可） |

### 社内ネットワーク・ファイアウォール環境での注意

本ツールは SRT に UDP を使用します。以下の環境では接続できない場合があります。

| ネットワーク環境 | 使用可否 |
|---|---|
| 外向き UDP が許可されている | ✅ 使用可能 |
| 外向き UDP が特定ポートのみ許可 | ⚠️ SRT のポート番号が許可リストにあれば使用可能 |
| 外向き UDP が全面ブロック | ❌ 使用不可（ネットワーク管理者への申請が必要） |
| HTTP プロキシ経由の通信のみ許可 | ❌ 使用不可（UDP はプロキシ非対応） |

> 社内ネットワークで使用する場合は、ネットワーク管理者に「接続先 IP アドレス・ポートへの**アウトバウンド UDP 通信の許可**」を申請してください。

### SRT Listener 側の要件

- SRT Listener として設定・起動されていること
- ファイアウォールで SRT のポートが**インバウンド許可**されていること
- パスフレーズを設定している場合は、正確な文字列が必要

## 5. インストールと起動

### 方法 A：Python がインストールされている PC で直接実行

#### 必要なもの

- Python 3.9 以上
- ffmpeg（ffprobe を含む）

#### 手順

**1. 依存パッケージのインストール（初回のみ）**

```
python -m pip install flask
```

**2. ffprobe の確認**

```
ffprobe -version
```

`ffprobe version ...` と表示されれば OK。表示されない場合は [ffmpeg 公式サイト](https://ffmpeg.org/download.html) からダウンロードし、PATH に追加してください。

**3. アプリの起動**

```
cd （ファイルを置いたフォルダ）
python app.py
```

**4. ブラウザで開く**

```
http://127.0.0.1:8765
```

**5. 終了**

コマンドプロンプトで `Ctrl + C`

## 6. スタンドアロン exe の作成と配布

Python がインストールされていない PC でも使用できる `.exe` ファイルを作成します。

### ビルドに必要なもの

- Python 3.9 以上（ビルドする PC のみ。配布先は不要）
- PyInstaller
- ffprobe.exe（ffmpeg パッケージの `bin` フォルダ内）

### ビルド手順

**1. ファイルの準備**

以下の構成でフォルダを用意します。

```
C:\srt_analyzer\
├── app.py
├── srt_probe.py
├── requirements.txt
├── ffprobe.exe        ← ffmpeg の bin フォルダから取得
└── templates\
    └── index.html
```

ffprobe.exe の入手先（Windows 向けビルド）:  
`https://www.gyan.dev/ffmpeg/builds/` → `ffmpeg-release-essentials.zip` をダウンロード → 解凍 → `bin\ffprobe.exe` を取り出す

**2. PyInstaller のインストール（初回のみ）**

```
python -m pip install pyinstaller
```

**3. ビルド実行**

```
cd C:\srt_analyzer
python -m PyInstaller --onefile --windowed --add-data "templates;templates" --add-binary "ffprobe.exe;." --name srt_analyzer_web app.py
```

完了すると `dist\srt_analyzer_web.exe` が生成されます。

**4. 動作確認**

`dist\srt_analyzer_web.exe` をダブルクリックし、ブラウザが開けば成功です。

### 配布方法

以下の **2 ファイル**を配布先 PC の同じフォルダにコピーします。

```
（任意のフォルダ）
├── srt_analyzer_web.exe
└── ffprobe.exe
```

> `ffprobe.exe` を同じフォルダに置くことで、exe 内への同梱が万一失敗した場合でも正しく動作します。

### 配布先 PC での使い方

1. `srt_analyzer_web.exe` をダブルクリック
2. ブラウザが自動で開く（開かない場合は `http://127.0.0.1:8765` を手動で開く）
3. 使い終わったら黒いコマンドウィンドウを閉じる

## 7. 画面の使い方

### 接続設定パネル

| 項目 | 説明 | 例 |
|---|---|---|
| **IP アドレス** | SRT Listener の IP アドレス | `192.168.1.100` |
| **ポート** | SRT Listener のポート番号（1〜65535） | `9998` |
| **パスフレーズ** | 暗号化設定がある場合のみ入力。なければ空欄 | （任意） |
| **Latency モード** | 自動スキャン / 固定値を選択 | 下記参照 |
| **タイムアウト** | 1 回の接続試行で待機する最大秒数 | `8` 秒 |

### Latency モード

**自動スキャン（推奨）**  
以下の値を順番に試し、接続できた最初の値を採用します。

```
120ms → 200ms → 500ms → 1000ms → 2000ms → 3000ms
```

**固定値**  
トグルをオフにして任意の Latency 値（ms）を指定します。SRT Listener 側の設定に合わせてください。

### 接続と解析

1. 接続設定を入力
2. **「▶ 接続 / 解析」** ボタンをクリック
3. プログレスバーで試行状況を確認
4. 接続成功 → ストリーム情報タブに結果が表示される

### 結果タブ

| タブ | 内容 |
|---|---|
| **ストリーム情報** | 映像（青背景）・音声（緑背景）のコーデック詳細テーブル |
| **フォーマット情報** | コンテナ全体のメタデータ |
| **Raw JSON** | ffprobe が返す生の JSON データ（整形済み） |
| **ログ** | 接続試行の経過・エラーメッセージ |

### ツールバーボタン

| ボタン | 機能 |
|---|---|
| **📋 URL コピー** | 接続成功した SRT URL をクリップボードにコピー |
| **⬇ JSON 保存** | 解析結果を `srt_probe_result.json` としてダウンロード |

## 8. トラブルシューティング

### 接続関連

| 症状 | 原因 | 対処 |
|---|---|---|
| すべての Latency でタイムアウト | SRT Listener が起動していない / IP・ポートが違う / ファイアウォールで UDP がブロックされている | Listener の起動状態・接続情報・ファイアウォール設定を確認 |
| タイムアウトはしないが解析失敗 | パスフレーズが間違っている | パスフレーズを再確認 |
| 特定の Latency のみ失敗 | Listener 側の Latency 設定が高い | より大きい Latency 値を試す、または固定値モードで指定 |

### ffprobe 関連

| 症状 | 原因 | 対処 |
|---|---|---|
| 「ffprobe が見つかりません」と表示 | ffprobe.exe が見つからない | exe と同じフォルダに ffprobe.exe を置く |
| 接続はできるが情報が少ない | ストリームのビットレート情報が未設定 | 配信機器側の設定を確認（正常な場合もある） |

### アプリ起動関連

| 症状 | 原因 | 対処 |
|---|---|---|
| ブラウザが自動で開かない | OS の既定ブラウザ設定の問題 | ブラウザで `http://127.0.0.1:8765` を手動で開く |
| 「ポートが使用中」エラー | 8765 番ポートを別のアプリが使用中 | 環境変数 `SRT_ANALYZER_PORT` に別のポート番号を設定して起動 |
| exe をダブルクリックしても何も起きない | セキュリティソフトがブロック | セキュリティソフトの除外設定に追加、または管理者権限で実行 |

## 9. 仕様・制限事項

### 仕様

| 項目 | 内容 |
|---|---|
| 対応 OS | Windows 10 以降 / macOS / Linux |
| Web UI アクセス | `127.0.0.1`（ローカルのみ）。外部 PC からのアクセス不可 |
| 同時接続 | 1 セッションのみ（複数同時解析には非対応） |
| デフォルトポート | 8765（`SRT_ANALYZER_PORT` 環境変数で変更可能） |
| 解析時の受信時間 | タイムアウト設定値に依存（デフォルト 8 秒） |

### 制限事項

- **SRT Caller / Rendezvous モードの Listener には非対応**（接続先は必ず Listener モードであること）
- **ストリームの録画・保存機能はありません**（解析のみ）
- **複数の SRT ストリームを同時に解析することはできません**
- **解析はスナップショット**です。接続した瞬間の情報を取得します。ビットレートが変動するストリームでは値が一致しない場合があります
- **パスフレーズに一部の記号（`&`, `=`, `%` など）が含まれる場合**、URL エンコードの関係で正しく渡せない場合があります
